How to use

  1. Download the archive for your OS and extract it.
  2. Run the arcs binary (double-click or from terminal).
  3. On first launch, create a desktop shortcut when asked.
  4. Click Discover → select items → Backup → set a password.
  5. To restore later: open Restore, pick the .arcs file, use dry-run first.

CLI: arcs discover · arcs backup -o out.arcs --path ~/.config --encrypt · arcs --tui
